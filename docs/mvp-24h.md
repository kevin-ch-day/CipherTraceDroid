# 24-hour MVP

The immediate objective is defensible evidence, not a general platform. Gates are: foundation; libpcap-based inspection; normalization and state-bounded windows; versioned feature CSV; strict session manifest; grouped classification; cross-state evaluations; and evidence export. Work outside this path, including live capture, decryption, dashboards, databases, and deep learning, is deferred.

The local PCAP prerequisite is Fedora package `libpcap-devel`; it is now detected through `pkg-config`. No host packages are installed by this repository itself.
