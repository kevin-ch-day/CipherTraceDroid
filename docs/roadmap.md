# Roadmap

## Paper MVP

Verify a capture vantage point; collect repeated device sessions; validate strict manifests/hashes; export feature CSV; group by session/run; run classical cross-state evaluations; export reproducible evidence.

## Post-paper research

Cross-device/version studies, state-transition analysis, additional classical models, and protocol characterization.

## Open-source tool development

Portable Linux support, CI, contributor documentation, guided device/capture setup, and reproducible examples.

## DEF CON preparation

Only after the evidence pipeline is trusted: an understandable live visualization of authorized encrypted-traffic metadata and controlled state changes.
